# PixelTunes Web - Quick Start Guide

Get up and running with PixelTunes Web in 60 seconds!

## ⚡ Fastest Start

1. **Open the web app**
   ```bash
   cd web
   python3 -m http.server 8000
   ```

2. **Visit in browser**
   - Open http://localhost:8000

3. **Upload music**
   - Click "Upload Files" or "Upload Folder"
   - Or drag & drop files onto the page

4. **Play and enjoy!**
   - Click Play button
   - Use controls to navigate

## 🎹 Keyboard Shortcuts

- **Space** - Play/Pause
- **←** - Seek backward 5s
- **→** - Seek forward 5s

## 💡 Pro Tips

1. **For best experience**, use Chrome or Firefox
2. **Use a local server** (not file://) for full features
3. **Organize files in folders** before uploading
4. **Switch themes** with the sun/moon icon
5. **Open playlist** to see all songs

## 🔧 Troubleshooting

### "Upload not working"
→ Use a local web server, not file://

### "Service Worker failed"
→ Needs HTTPS or localhost

### "No audio playing"
→ Check file format is supported
