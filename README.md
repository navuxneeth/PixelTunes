# PixelTunes 🎵

A fun, lossless audio player with a nostalgic pixel-themed design! PixelTunes brings retro aesthetics to modern audio playback, supporting high-quality lossless formats like FLAC, WAV, and ALAC.

## 🎮 Features

- **Lossless Audio Support**: Play FLAC, WAV, ALAC, and other high-quality audio formats
- **Pixel-Perfect Design**: Retro 8-bit themed interface with smooth animations
- **Cross-Platform**: Available as both a web app and Android app
- **Lightweight**: Fast and efficient audio playback
- **User-Friendly**: Simple, intuitive controls with a nostalgic twist

## 🌐 Web App

The PixelTunes web app provides a browser-based audio player with full lossless audio support. Simply open `website/index.html` in your browser to start playing your favorite tracks.

### Features:
- Drag-and-drop file support
- Playlist management
- Waveform visualization
- Pixel art UI elements

## 📱 Android App

The PixelTunes Android app brings lossless audio playback to your mobile device with a beautiful pixel-themed interface.

### Features:
- Support for FLAC, WAV, ALAC formats
- Material Design with pixel aesthetics
- Background playback
- Lock screen controls
- Playlist support

### Building the Android App

```bash
cd android
./gradlew assembleDebug
```

## 🚀 Getting Started

### Web App
1. Clone this repository
2. Open `website/index.html` in your browser
3. Drop your audio files and enjoy!

### Android App
1. Open the `android` folder in Android Studio
2. Build and run on your device or emulator

## 📦 Supported Formats

- **FLAC**: Free Lossless Audio Codec
- **WAV**: Waveform Audio File Format
- **ALAC**: Apple Lossless Audio Codec
- **MP3**: MPEG Audio Layer III (for compatibility)
- **OGG**: Ogg Vorbis

## 🎨 Design Philosophy

PixelTunes embraces the charm of retro computing with:
- 8-bit style fonts
- Pixel art icons and buttons
- Chiptune-inspired UI sounds (optional)
- Classic color palettes
